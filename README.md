**MY TASK APP**

A simple and efficient Task Manager application built to organize daily tasks.

**Features**

- Add new tasks easily
- Pending task section
- Mark tasks as completed using checkbox/tick option
- Automatically move completed tasks to the completed section
- Clean and user-friendly interface

**Purpose**

This project was created to practice task management logic, frontend development, and basic application workflow.

**Technologies Used**

- HTML
- CSS
- JavaScript

**Future Improvements**

- Task editing feature
- Task deletion option
- Local storage/database support
- Dark mode UI
